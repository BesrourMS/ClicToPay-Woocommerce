# WooCommerce ClicToPay Payment Gateway

## Description

The WooCommerce ClicToPay Payment Gateway plugin allows you to accept Tunisian bank card payments on your WooCommerce store. It integrates seamlessly with the ClicToPay payment service, providing a secure and convenient payment option for your customers.

## Features

- Accept Tunisian credit card payments
- Sandbox mode for testing
- Customizable payment title and description
- Configurable order status after successful payment
- Supports both sandbox and production environments

## Installation

1. Download the plugin zip file.
2. Log in to your WordPress admin panel.
3. Navigate to Plugins > Add New.
4. Click on the "Upload Plugin" button at the top of the page.
5. Choose the downloaded zip file and click "Install Now".
6. After installation, click "Activate Plugin".

## Configuration

1. Go to WooCommerce > Settings > Payments.
2. Click on "ClicToPay Gateway" to configure the plugin settings.
3. Enable the payment method by checking the "Enable/Disable" box.
4. Fill in the following details:
   - Title: The name of the payment method displayed to customers
   - Description: Additional information shown to customers during checkout
   - Instructions: Any specific instructions for customers after payment
   - Order Status: Choose the status for orders after successful payment
   - Sandbox Mode: Enable for testing purposes
   - API Credentials: Enter your ClicToPay API login and password for both sandbox and production environments
   - API URLs: Enter the sandbox and production URLs provided by ClicToPay

## Usage

Once configured, the ClicToPay payment option will appear on the checkout page of your WooCommerce store. Customers can select this option to pay using Tunisian credit cards.
